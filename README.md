# AI資格学習室

G検定・生成AIパスポートの教本と四択演習、G検定の会話学習をまとめたPWAです。

- [通常のドリル](https://makoto-design.github.io/g-kentei-drill/)
- [G検定を会話で学習する（全32講・192単位）](https://makoto-design.github.io/g-kentei-drill/conversation.html)
- [生成AIパスポート](https://makoto-design.github.io/g-kentei-drill/?exam=passport)

会話学習では、説明・図解を読み、4択に答え、確認タイムで補足や別の例を確認できます。「ChatGPTと会話で学ぶ」で最大3単位の授業用文章をコピーし、ChatGPTへ貼り付けて送信すると、音声または文字で学べます。APIキーは不要です。ChatGPTの回答はアプリへ自動同期されません。

ブラウザの「アプリをインストール」でホーム画面から開けます。オンラインで一度読み込んだ後は教材をオフラインでも利用できます。ChatGPTの利用には接続が必要です。

学習記録はこの端末・このブラウザに保存されます。通常ドリル・会話学習・パスポートは別の記録です。G検定側の「記録を全消去」はG検定の通常ドリルと全講の会話記録を削除し、パスポート側の全消去はパスポートの記録だけを削除します。端末・ブラウザ・公開元が変わると記録は共有されません。

収録問題は自作です。試験機関の公式問題集からの転載は含みません。学習の補助としてお使いください。

## 開発と再生成

この公開リポジトリは、非公開の `g-kentei-study` の `tools/deploy_drill.js` が書き出す生成先です。原本側のアプリ資産・会話教材・生成処理にも変更を取り込んでから公開してください。公開側だけの編集は次回生成で失われます。

会話教材の編集元は `content/`、30講の生成器は `scripts/build-conversation-course.cjs` です。M2-01とM2-02の手作業で編集した教材、図解、会話引継ぎ用の文章も保持しています。既存の `js/lessons.js` と `js/data.js` を原典として使い、会話学習の生成で上書きしません。

```sh
npm install
npm run check
```

`check` は30講・164単位を再生成し、M2-01の16単位・M2-02の12単位と合わせた全32講・192単位、通常ドリル、パスポート、保存と再開、コピー、サブパスのリンク、Service WorkerをDOMテストで検証します。実ブラウザの描画・OSクリップボード・実機での音声切替は別途確認が必要です。

[操作・保存仕様・教材と生成処理の詳細](docs/conversation-mode.md)
