# AI資格学習室

G検定・生成AIパスポートを切り替えて学ぶ四択演習アプリ。**このリポジトリの中身は自動生成物です。**

- 問題と画面の原本は別リポジトリ（非公開）にあり、`node tools/deploy_drill.js` で書き出しています
- ここを直接編集しても、次回の書き出しで上書きされます

## 使い方

1. 公開URLをブラウザで開く
2. Chrome の「アプリをインストール」を選ぶ（Android・Windows とも）
3. オフラインでも動きます

**学習記録は端末のブラウザ内に保存されます。** 共有ボタンを押した場合だけ共有先を選べます。アカウント登録は不要です。
記録を消したいときは、アプリの成績画面から「記録を全消去」を実行してください。

## 問題について

収録している問題はすべて自作です。試験機関の公式問題集からの転載は含みません。
内容の正確性は保証しません。学習の補助としてお使いください。
