# G検定ドリル

G検定の四択演習アプリ。**このリポジトリの中身は自動生成物です。**

- 問題と画面の原本は別リポジトリ（非公開）にあり、`node tools/deploy_drill.js` で書き出しています
- ここを直接編集しても、次回の書き出しで上書きされます

## 使い方

1. 公開URLをブラウザで開く
2. Chrome の「アプリをインストール」を選ぶ（Android・Windows とも）
3. オフラインでも動きます

トップ画面の「ChatGPTで復習」から、これまでの成績・苦手分野・直近の履歴を共有できます。
テスト結果では、その回の誤答と解説だけに絞った復習データも共有できます。
成績画面では、累計成績・講別習得度・直近の履歴をまとめて共有またはコピーできます。
Androidでは共有先の選択画面を開き、利用できない場合はクリップボードへコピーします。

**学習記録は端末のブラウザ内にのみ保存されます。** 自動的な外部送信やアカウント登録はなく、
共有ボタンを押した場合だけ、選択した共有先へ復習用テキストを渡します。
記録を消したいときは、アプリの成績画面から「記録を全消去」を実行してください。
