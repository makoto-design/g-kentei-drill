# 会話で学習 v6.2

## 対象と入口

G検定の全32講・192単位を収録します。M2-01は16単位、M2-02は12単位、残り30講は164単位です。通常ドリルとパスポートの教本・四択問題は従来のものを使います。

- [全講の会話学習ホーム](https://makoto-design.github.io/g-kentei-drill/conversation.html)
- [講の例：M2-01](https://makoto-design.github.io/g-kentei-drill/conversation.html?lesson=M2-01)
- [通常ドリル](https://makoto-design.github.io/g-kentei-drill/index.html?exam=g-kentei)

通常ドリルのホームから全講を選べます。各G検定講のメニューからも対応する会話学習へ進めます。パスポートには会話学習の入口を表示しません。`conversation.html` が講一覧、`conversation.html?lesson=M1-01` などが各講です。公開先の `/g-kentei-drill/` で動く相対URLを使っています。

## 操作

説明 → 4択（押すと回答確定）→ 確認タイム → 次の単位、の順に進みます。長い説明はページを分けて表示し、読み終えてから問題へ進みます。確認タイムは自動で次へ進みません。

「もう少し詳しく」「別の例で説明」「もう一度説明」は用意した補足を表示します。「元の説明に戻る」（回答後は「確認タイムに戻る」）で、開く前の説明ページ・スクロール位置・押したボタンへ戻ります。補足や回答後の読み返しで、回答記録や現在の学習位置は進みません。全単位完了後も各説明と教本の資料を見返せます。

「ChatGPTと会話で学ぶ」では音声／文字、1単位／ここから最大3単位を選べます。授業用文章をコピー → ChatGPTを開く → 貼り付けて送信、の順です。音声を希望する場合は同じチャットで利用できる音声会話へ手動で切り替えます。「AIに聞く」は今の教材・問題・回答に自分の疑問を添えてコピーできます。自動コピーが使えなければ文章を表示して手動コピーできます。

生成AI API・APIキー・自動送信は使いません。ChatGPTでの回答・会話の結果はアプリへ同期されません。アプリ内で4択に答えると記録されます。

## 記録と再開

通常ドリルは `gken_store_v1`、パスポートは `aipass_2027_store_v1`、会話学習は講ごとに `gken_conversation_m1_01_v1` などの別キーで保存します。M2-01とM2-02の既存キーは維持します。全講一覧の再開位置は `gken_conversation_last_lesson_v1` です。

保存するのは教材バージョン・単位・画面段階・説明ページ・各回答と正誤・時刻です。M2-01の旧9単位の回答も維持し、追加された未回答単位から再開できます。保存不能や破損時は案内を出し、学習は続けられます。同時に開いた複数タブの編集を同期する機能はありません。

- 会話学習の「最初からやり直す」は、確認後にその講だけを初期化します。
- G検定の成績画面の「記録を全消去」は、通常ドリルと全講の会話学習・再開位置を削除します。
- パスポート側の全消去はG検定の記録を消しません。
- 記録は端末・ブラウザ・オリジンごとです。Sitesでの記録はGitHub Pagesには自動移行しません。

Service Worker登録と教材キャッシュの作成後は、通常ドリル・パスポート・全講の会話学習をオフラインで開けます。初回アクセスとChatGPTには接続が必要です。HTML・JSはネットワークを優先し、接続できない場合はクエリを除いたキャッシュを探します。存在しないJSへ別画面のHTMLを返すことはありません。キャッシュと通信の対象はこのアプリのサブパス内です。

## 教材の原本と再生成

| パス | 役割 |
| --- | --- |
| `js/lessons.js`, `js/data.js` | 既存の教本と問題。会話教材の生成では変更しない |
| `js/conversation-data.js`, `content/m2-01-expansion.json` | M2-01の16単位と追記原稿 |
| `content/m2-02.json`, `js/conversation-m202-data.js` | M2-02の12単位の原稿と配信データ |
| `content/course-editorial.json` | 残り30講の分割・要点・詳説・例・図解・問題の対応 |
| `scripts/build-conversation-course.cjs` | 既存教本の本文を保持し、30講を決定的に生成するコンパイラ |
| `js/conversation-course-data.js` | 生成された30講・164単位と教本の補足資料 |
| `content/conversation-handoff.json`, `js/conversation-handoff.js` | ChatGPTへ渡す授業進行の原稿と実装 |
| `js/conversation-*-visuals.js`, `js/conversation-visuals.js` | 図解と比較表示 |

```sh
npm install
npm run build:course
npm test
```

`node scripts/build-conversation-course.cjs <出力先>` とすると、指定先の `js/lessons.js`・`js/data.js` を読み、同じ場所に会話教材を生成できます。編集原稿はコンパイラと同じリポジトリの `content/` から読みます。

非公開原本では `app/` が配信資産、`content/` が編集原稿、`tools/build_conversation_course.cjs` がコンパイラの原本です。`node tools/deploy_drill.js <公開先>` は通常教材を生成した後に会話教材を必ず作り直し、公開用の生成器・編集原稿・検証コード・この案内も書き出します。通常ドリルの入口、講リンク・全消去、Service Workerもこの工程に含まれます。公開先の `js/exam.js` は教材ごとのハッシュを埋め込み、両HTML入口と事前キャッシュのJS・CSSのURLには最終内容のハッシュを付けます。会話HTML・CSS・JSの変更もService Workerのキャッシュ世代へ反映されます。

DOMテストは全32講・192単位の説明・ページ送り・補足・正答／誤答・完了、保存と再開、授業文章の範囲とコピー成功／失敗、通常ドリルとパスポート、公開サブパス上のリンク・入口・リセット、Service Workerの事前キャッシュ・更新・オフライン応答を確認します。教本・問題・パスポートなどの原典資産は移植前のSHA-256と照合します。
