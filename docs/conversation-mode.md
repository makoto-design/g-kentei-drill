# 会話で学習：M2-01 試作

## スマホで試す

公開ページの「会話で学習」または `/conversation.html` を開きます。
説明 → 4択（押すと回答確定）→ 確認タイム → 次の単位、の順です。
確認タイムは自動で次へ進みません。「もう一度説明」「別の例で説明」は用意した文章を表示します。

「AIに聞く」は質問文をコピーします。「ChatGPTを開く」から移動し、入力欄を長押しして貼り付け、自分で送信します。
通常のHTTPSリンクのため、Androidのアプリリンク設定によりChatGPTアプリまたはブラウザで開きます。
アプリが開かないときは手動で切り替えてください。自動コピーが拒否された場合も、質問文を選択してコピーできます。
API・APIキー・自動送信は使いません。

ページを閉じても同じ端末・同じブラウザなら「前回の続きから」で説明／問題／確認タイムのいずれからも再開できます。
ブラウザのデータ削除、プライベートブラウズの終了、別端末への移動では記録は引き継がれません。
オフライン利用は、オンライン時のService Workerキャッシュ作成後に可能です。ChatGPTの利用には接続が必要です。

## 教材の対応

基準は `js/lessons.js` の M2-01、blob `9bd2d58623e527e0caba85fb93422fbc74ca435f`。
教本そのものは変更せず、同じ流れを `js/conversation-data.js` に短く再編集しました。
1単位は本文約370〜450字＋要点、読み込み方に応じた補足・別例です。

| 単位 | 教本の対応箇所 | 内容 |
| --- | --- | --- |
| 1 | 話の流れ・冒頭 | 教師あり学習、特徴量、教師データ |
| 2 | まず、何を当てるのか | 回帰、分類、多クラス分類 |
| 3 | いちばん素直な当て方 | 線形回帰 |
| 4 | 同上 | 単回帰、重回帰 |
| 5 | 同上 | ロジスティック回帰 |
| 6 | 時間の流れを持つデータ | AR、VAR |
| 7 | 境界の引き方を工夫する・前半 | SVM、マージン最大化 |
| 8 | 同・コインの例 | 入力の変換、高次元での分離 |
| 9 | 同・後半、用語の整理 | カーネルトリック |

用語の区別のため、単位8の補足では特徴写像とカーネル関数を区別します。単位9の「内積」は教本の用語欄に基づきます。
線形回帰の数式、しきい値、別の例は理解用の具体化です。原本の代わりに別教材を読ませる構成ではありません。
決定木以降、および他の講は対象外です。正解位置は 2,4,1,3,2,1,4,3,1。

## 保存と分離

既存と同じ `localStorage` を使いますが、キーは `gken_conversation_m2_01_v1` として分離します。
通常ドリルは読み込み時に保存項目を限定しているので、同じオブジェクトに混ぜると消える危険があるためです。
保存内容は教材バージョン、現在単位、画面段階、各単位の選択・正誤・回答時刻、最終更新時刻です。
保存失敗や破損は画面に表示し、学習は継続できます。複数タブの同時編集の同期は対象外です。

- 通常ドリルの習得度・弱点一覧には合算しません。
- 「最初からやり直す」は確認後にこのモードの記録だけを初期化します。
- G検定の成績画面の「記録を全消去」はこのモードも削除します。
- パスポート側の全消去ではG検定の記録を消しません。

## 原本への取り込み（重要）

この公開リポジトリは `g-kentei-study` の `tools/deploy_drill.js` による生成先です。
今回の公開側の追加だけでは、次回の生成時に入口やキャッシュ設定が上書きされる可能性があります。
継続採用する場合、原本の次の箇所へ同じ変更を移してください。

1. 静的ファイルのコピー対象に `conversation.html`, `css/conversation.css`, `js/conversation-data.js`, `js/conversation.js` を追加。
2. HTMLテンプレートにホームとM2-01講メニューの入口を追加。パスポートでは非表示。
3. app.js原本にM2-01の入口表示条件、G検定側の全消去処理を追加。
4. style.css原本に入口のリンク書式とパスポート非表示条件を追加。
5. sw.js原本のPRECACHEに新規4ファイルを追加し、生成時のキャッシュ世代更新を維持。
6. js/exam.js と index.html のスクリプト参照ハッシュは原本の生成工程で再計算。

この試作では、指定された公開リポジトリのみ変更し、別の非公開原本は変更していません。

## 検証を再実行

Node.js、Python、PlaywrightとChromiumがある環境で、リポジトリ直下から：

```sh
python -m http.server 8765
# 別のターミナル
node tests/conversation.spec.cjs
```

Playwrightが未導入なら `npm install --no-save playwright` と `npx playwright install chromium` で準備します。
`TEST_CHROMIUM_PATH` で既存Chromiumの実行ファイル、`TEST_BASE_URL` でテスト先、`TEST_SCREENSHOT_DIR` でスクリーンショットの保存先を変更できます。
テストは専用ブラウザコンテキストで実行し、普段のブラウザの記録には触れません。
